Envision project  Orange Labs – 2011

Configuration d'un système gérant la transformation d'un flux unicast en multicast pour qu’un opérateur réseau puisse, de façon transparente ou en collaboration avec une application overlay, tirer profit du multicast pour gérer le trafic live événementiel.

  • Techniques : NAT, filtrage, routage multicast static
  • Technologies : PIM SM SSM, IGMPv3, ISIS
  • Outils réseaux : Serveur N2X (simulation de traffic), iptables, smcroute, SSH, Routeur Juniper M7i, Junos SDK 10.4
